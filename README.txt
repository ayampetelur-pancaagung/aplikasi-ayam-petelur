APLIKASI MANAJEMEN AYAM PETELUR — SKALA KECIL / MULTI-USER

Konsep penggunaan:
- Petugas kandang merangkap penjualan telur dan pencatatan keuangan.
- Admin/Kepala hanya memantau, merekap, mencetak, dan mengelola pengguna.
- Cocok untuk usaha kecil dengan satu kandang/kelompok utama dan beberapa petugas bila diperlukan.

FITUR PETUGAS:
- Login sendiri.
- Input produksi telur harian dan telur rusak/pecah.
- Input penjualan Grade A, B, C dan harga per tray.
- Input penjualan eceran.
- Input pengeluaran: pakan, obat/keswan, transportasi, perbaikan, pembayaran hutang, dan lainnya.
- Melihat laporan miliknya sendiri.

FITUR ADMIN:
- Melihat seluruh laporan semua petugas.
- Filter berdasarkan petugas dan tanggal.
- Melihat produksi, penjualan, pengeluaran, dan saldo bersih.
- Mengelola akun petugas.
- Cetak/PDF dan ekspor CSV.

DATA:
- Data disimpan terpusat pada server dalam data/data.json.
- Bukan lagi hanya tersimpan di browser petugas.

MENJALANKAN:
1. Instal Node.js 18 atau lebih baru.
2. Buka terminal di folder aplikasi.
3. Jalankan: npm install
4. Jalankan: npm start
5. Buka: http://localhost:3000

CATATAN PENTING:
Untuk digunakan dari beberapa HP, aplikasi harus dijalankan pada komputer/server yang dapat diakses perangkat lain dalam jaringan atau di-host pada server/cloud. Untuk penggunaan internet publik, gunakan HTTPS, firewall, backup, dan database server yang aman.
